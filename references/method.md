# 选题方法论详情（topic-diagnose 参考）

## 一、选题本质

选题 = 需求 + 解决方案 + 视角
- 需求：观众要什么（走捷径/赚钱/不焦虑）
- 解决方案：你给什么答案
- 视角：你从哪个角度切入

需求元方法 = 走捷径（所有需求里最硬的）。任何选题先问"是不是在帮目标人群走捷径"。

选题定生死：选题/标题/开头/封面是一回事，一次性定，不存在"先写稿再补标题"。稿子一诞生，标题的死活已经定了。

选题输出范围不由知识储备决定，由"能把事搞清楚的方法"决定。会拆解，选题无限。

## 二、选题分类

### A类选题（天然吸引人，直接说）
有稀缺/亮眼的事，封面=标题=开头=正文，平铺直叙。判断标准：问"我这个事够不够稀缺、够不够少见"。

### B类选题（需包装，95%日常）
天然吸引力弱，需挖隐含优点包装。只要业务在盈利，一定有受众买单的理由（隐含优点），把它说出来。

## 三、六种张力结构（选题类型）

1. 反常识断言：常识 vs 结论落差（最强，dontbesilent主力）。如"赚钱最大的弯路是想找一个自己擅长的事"
2. 痛点归因：你正在亏钱/失败的根因落差。如"你说的每一个模糊的词，都在让你亏钱"
3. 方法承诺：你不知道 vs 我知道答案的缺口落差。如"如何在要脸的情况下做好自媒体"
4. 现象评议：借外部事件/人物/平台做判断落差。如"善良的李亚鹏30年为什么赚不到钱"
5. 身份立场：我这么做 vs 别人那么做的认同落差。如"我坚持非必要不读书"
6. 是否辩题：站队落差（最弱，不建议用）

## 四、七个陌生化手法

1. 造词溯源：把熟悉概念重新命名，或溯源"这个词之前是什么词"。如"收口四步"代替"短视频结尾"
2. 找没人讲过的切口：找"真实存在但没人单独出内容讲"的子需求，讲出来天然陌生化
3. 反认知断言：把常识结论反过来下断言（dontbesilent主力，36次）
4. 带情绪登场：带生气/开心/大吼/不说话/情绪低落出场，靠情绪本身制造悬念
5. 筹码前置：认清最火的元素（王炸），押大赌注放开头
6. 人设符号：把人物小习惯细节反复植入每条视频+反复念名字
7. 爆点前置：开头就把最爆的点先展示

## 五、陌生化生成机制（三维置换）

陌生化 = 固定其中一维，置换另两维。每次置换都是一个新选题，且不同质。

- 方向1 固定需求换视角：同需求扫所有"大家以为是正路"的视角，逐个判弯路
- 方向2 固定结构换领域：把验证过的结构迁移到学习/社交/做IP/恋爱
- 方向3 固定观点换包装：造词/类比/情绪登场/筹码前置

演示：dontbesilent「赚钱最大的弯路是找擅长的事」
- 方向1：弯路是钻研流量 / 弯路是模仿对标 / 弯路是提升认知
- 方向2：学习最大弯路是找方法 / 做IP最大弯路是找定位
- 方向3：造词"天赋陷阱" / 类比"像用软枕治失眠" / 情绪登场

一个选题 → 三维置换 → 10+ 陌生化变体，每个都不同质。

## 六、普遍性判断标准

想好选题/开头后：
- 搜有没有人做过、做火过
- 做火过 = 有真需求（可做，但需陌生化避免同质化）
- 大量人在讲 = 普遍性强（必须陌生化）
- 没做过 = 没需求（慎做）

判断术语好坏的标准：这个说法能不能让我分清"下一步该干什么"。能分清才是方法，分不清只是感觉。反对"吸引人"这种模糊词。

## 七、注意力机制

- 小红书标题 = 双列多选一，重要词前置（用户浏览不看全，只看关键词）。20字含标点19字，大字报放封面
- 抖音开头 = 单列防划走，前5-15秒给"值得我浪费这几分钟"的理由
- 标题和开头注意力机制不同，不能混用

## 八、dontbesilent实战分布（参考基准）

66条2026视频手法分布（多手法分别计数）：
- 反认知断言 36次（主力）
- 找没人讲过的切口 18次（第二）
- 筹码前置 7次
- 人设符号 4次

- 反常识断言 25条

## 九、可操作流程

1. 选题触发：从需求出发（走捷径），问"这条视频满足什么需求"
2. 选题定性：A类（直接说）还是B类（挖隐含优点包装）
3. 陌生化生成：拆三维，跑三维置换，生发变体
4. 普遍性校验：搜是否有人做火过，普遍性强=必须再陌生化
5. 注意力适配：小红书标题关键词前置，抖音开头5秒给理由
6. 判断力兜底：给20个选项做选择题，选错的根因是刷爆款不够
